## Set Detail View

This page shows every record in a single set, with its own summary,
FAIR breakdown, and a searchable, sortable record table. You normally
arrive here by clicking a row on the main dashboard; the set you are
looking at is always shown in the badge next to the page title.

### Summary and FAIR scores

The strip near the top mirrors the dashboard's overall summary, but
scoped to this one set: record count, pass/fail/indeterminate rates,
and the maturity level distribution. Below that, the same four FAIR
principle bars as the dashboard — Findable, Accessible,
Interoperable, Reusable — but calculated only from this set's
records.

### The record table

Each row is one record (identified by its OAI-PMH identifier), with
its net test score and maturity level. Use the search box above the
table to filter by identifier — matching is partial, so a fragment of
an identifier is enough.

> Tip: Click **Identifier**, **Net Score**, or **Maturity** in the
> table header to sort by that column, and click again to reverse the
> order.

Large sets are paginated; use the **Previous** / **Next** buttons
below the table to move between pages.

### Record detail panel

Click any row, or press Enter or Space while it has focus, to open a
side panel with everything recorded for that identifier:

- **FAIR Summary** — the pass rate for each FAIR principle, for this
  record alone.
- **Test Results** — every individual test that was run, and whether
  it passed, failed, or was indeterminate.
- **Narratives** — the FAIR Champion's own explanation of what each
  test checked and what it found, where available.
- **Guidance** — suggested next steps for tests that did not pass,
  where the assessment provided any.

Close the panel with the **✕** button, by clicking outside it, or by
pressing Escape.

### Getting back to the dashboard

Use **← Dashboard** in the top-left of the header to return to the
main overview at any time.
