1. Confirm the app boots with tenancy enabled
bashcurl -s -i http://localhost:8080/actuator/health
Should return 200 and {"status":"UP"}. If you don't have health exposed, just check the app didn't crash on startup in your console.

2. Confirm unauthenticated requests are rejected
bashcurl -s -i http://localhost:8080/api/results/summary.json
Expect 401 with the {"error":"Missing or invalid API key"} body from TenantAuthFilter. This is the most important check — it confirms the filter is now actually in the chain (which it wasn't, before SecurityConfig existed).

4. Generate manifests per tenant
bashcurl -s -X POST http://localhost:8080/api/generate-manifest \
  -H "X-API-Key: key-org-alpha" | jq .

curl -s -X POST http://localhost:8080/api/generate-manifest \
  -H "X-API-Key: key-org-beta" | jq .
This is the call that previously NPE'd on tenantContext.getTenantId() being null — it should now succeed cleanly, since the filter actually runs and sets the tenant ID before the request reaches BenchmarkService.

5. Verify isolation

curl -s http://localhost:8080/api/results/summary.json -H "X-API-Key: key-org-beta"  | jq '.languages'
